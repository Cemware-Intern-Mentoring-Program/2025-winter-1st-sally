👽 데이터베이스의 필요성
- 많은 데이터를 안전하게 저장, 조회, 수정, 삭제하기 위해
- 동시성 제어, 트랜잭션 보장, 영속 저장, 대규모 데이터 처리를 안정적으로 수행

> ⭐ 정리: 데이터베이스란, 많은 데이터를 안전하고, 빠르고 일관성있게 저장, 조회, 수정, 삭제할 수 있게 만든 전문 시스템

👽 데이터베이스의 종류
1. 관계형 데이터베이스(RDBMS)
2. NoSQL 데이터 베이스

👽 관계형 데이터베이스(RDBMS)
- 예: MySQL, PostgreSQL, Oracle, SQL Server

- 테이블 구조: 행과 열(row and column)
- 스키마 기반: 각 테이블의 구조(컬럼 이름, 타입 등)가 미리 정의
- SQL 이라는 표준 언어로 조회/저장/수정/삭제
- 트랜잭션, 무결성, 참조 관계 지원이 매우 강력

👽 NoSQL 데이터 베이스
- 스키마가 유연하거나, 대규모 분산 시스템을 위해 등장한 DB
- 유연한 구조
- 비정형 데이터에 강함
- 문서 (Document) DB
- 예: MongoDB
- JSON과 비슷한 문서 형태로 저장
- 컬렉션 안에 문서들이 들어있는 구조
- 키-값(Key-Value) DB
- 예: Redis
- Key와 Value의 단순 매핑
- 캐시, 세션과 같은 간단하고 빠른 저장용
- Wide-Column/Column Family DB
- 예: Cassandra, HBase
- 컬럼 단위 저장에 최적화
- 아주 많은 데이터 처리에 강함
- 그래프 DB
- 예: Neo4j
- 노드와 간선으로 관계 표현
